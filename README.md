## Cómo trabajo

Casi todas estas apps resuelven algo concreto de alguien: una rutina de
fisioterapia, un control de gastos privado, una dieta en dos idiomas. Eso marca
las decisiones técnicas más de lo que parece.

- **Los datos se quedan donde el usuario los deja.** Varias de estas apps
  manejan información de salud o de dinero, así que no tienen servidor: la
  garantía más fuerte de privacidad es no tener adónde enviar nada.
- **Elijo la herramienta por el problema, no al revés.** SharedPreferences para
  unos cientos de pares fecha-valor; SQLCipher cuando hay que cifrar de verdad;
  ningún framework cuando la app es una sola pantalla que debe abrir al
  instante.
- **Escribo pruebas para lo que no se ve.** Un test que mide animaciones vivas
  detecta una fuga de batería que ninguna revisión a ojo encontraría.
